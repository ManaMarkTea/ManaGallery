# Sample model

Upload `building-sheep.glb` to try model uploads, automatic thumbnails and the
3D viewer. It is a small sheep pen from Kenney's Hexagon Kit 2.0 (CC0).

Source: https://kenney.nl/assets/hexagon-kit
License: [Kenney's included license](KENNEY-LICENSE.txt).

This copy has the original `Textures/colormap.png` embedded in the GLB so it can
be uploaded as one file. Geometry, UVs and materials are unchanged. The sample
asset remains CC0; the gallery source code uses MIT.
